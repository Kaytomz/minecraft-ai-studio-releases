# Minecraft AI Studio — Téléchargements Windows

Ce dépôt distribue les installateurs et métadonnées de mise à jour de Minecraft AI Studio, une application Windows de création et gestion de serveurs Minecraft Java locaux.

## Installation

Ouvrir la page Releases et télécharger l’installateur Windows x64 de la dernière version publiée. Les versions actuelles sont distribuées sans signature de code Windows : un avertissement d’éditeur inconnu peut apparaître.

Les fichiers `latest.yml` et `.blockmap` servent au mécanisme de mise à jour. Les projets, mondes et sauvegardes sont conservés hors du dossier d’installation. Une sauvegarde est effectuée avant l’installation d’une mise à jour, qui demande confirmation.

Application en préversion : consulter les notes de chaque version pour connaître les limites et validations restantes. Les sources de l’application ne sont pas publiées dans ce dépôt.
